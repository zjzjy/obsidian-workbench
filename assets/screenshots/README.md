# 截图清单

建议统一用 **1600 × 900**、Minimal 主题浅色模式，截之前检查一遍有没有真实姓名、客户名、微信头像、私人日记正文或带 token 的链接。

| 文件名 | 拍什么 | 画面里最好出现 |
|---|---|---|
| `home.png` | Home 首屏 | 年 / 月进度、Inbox、待抓取、最近活动 |
| `dayline.png` | Dayline 日历 + 时间线 | 有缩略图的日子、心情色点、当天摘要 |
| `process.png` | 加工前后对比 | 左边是原始随记，右边是加工后的摘要 + 双链 |
| `output.png` | 一个自媒体内容页 | 选题、脚本、DLink 画廊、发布字段 |

## 拍摄建议

1. 加工前后对比用一篇自己写的**示例日记**，不要用真实日记。
2. 左侧文件树可以折叠到只剩 00PeriodicNotes / 01Projects / 02Areas / 03Resources 这几个一级目录。
3. 截图里不要出现「客户名 / 公司内部项目名 / 面试进度 / 私人聊天」。
4. 四张图放好后，打开根目录 `README.md`，把「界面截图」一节里的 HTML 注释去掉即可。
